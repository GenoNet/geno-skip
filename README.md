# 動画広告をぶっ飛ばすChrome拡張

YouTubeやニコニコ動画などの動画・広告を16倍速で再生するChrome拡張機能です。

## インストール方法

### 1. リポジトリをダウンロード

- GitHub の [Code] → [Download ZIP] をクリック
- ダウンロードしたZIPファイルを解凍

### 2. Chrome に拡張機能を読み込む

1. Chrome で `chrome://extensions/` を開く
2. 右上のデベロッパーモードをオン
3. 「パッケージ化されていない拡張機能を読み込む」をクリック
4. 解凍したフォルダを選択
5. 動画のタブを再読み込み

### 3. 拡張機能をピン留め

- ブラウザ右上の拡張機能アイコンをクリック
- 「じーのスキップ」のピンアイコンをクリック

## 使い方

### 基本操作

- 対応サイトで動画を開く
- プレーヤー下部のじーのちゃんボタンをクリックすると16倍速に加速
- 加速中は怒り顔になって回転
- YouTubeの広告は自動で16倍速。広告が終わると元の速度に戻る
- YouTubeの広告は、SKIPボタンが押せるようになったら自動でクリック
- 顔ボタンで解除すると、その広告の間は自動加速を停止
- 手動の加速は、もう一度クリックするか3秒で解除
- SキーやポップアップのGo!/Stop!ボタンでも操作可能
- 手動の加速中はミュート。解除後は元の再生速度・音量・ミュート状態に戻る
- 手動の加速は動画終了やページ内の別の場所のクリックでも解除

### 設定

1. ツールバーのじーのスキップアイコンをクリック
2. 加速キーを1文字で入力（初期設定はS）
3. 対応サイトを1行に1つ入力（例：youtube.com）。URLでも登録可能
4. 「設定を保存」をクリック

設定は保存後すぐに反映されます。拡張機能を更新したときはタブを再読み込みしてください。

- youtube.com を登録すると www.youtube.com も対象
- サイト一覧を空にすると全サイトで無効
- 拡張機能の詳細画面の「拡張機能のオプション」からも設定可能

## 補足

- YouTubeは操作バーのボタン列の左端、それ以外は動画の下に顔ボタンを表示
- 自動SKIPはYouTubeのみ。押せるボタンがない広告はスキップしません
- iframe内の動画や独自プレーヤー、DRM動画、ライブ配信などは動かない場合あり
- 動画だけを全画面にすると顔ボタンが隠れる場合あり。その場合はキーで操作
- 倍率は16倍速固定
- 広告通信の遮断は行いません。広告ブロッカー判定を受けない保証はありません

Chromiumの場所を変える場合は `CHROMIUM_EXECUTABLE_PATH=/path/to/chromium npm test` で指定できます。
