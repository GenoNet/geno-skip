# じーのスキップ

動画プレーヤーの geno ちゃんの顔ボタンやキー操作で、動画を**3秒間16倍速**にする Chrome 拡張機能です。加速中は怒り顔に切り替わって回転し、解除すると穏やかな顔に戻ります。

## インストール

1. このリポジトリをダウンロードするか clone します。
2. Chrome の `chrome://extensions/` でデベロッパーモードを有効にします。
3. 「パッケージ化されていない拡張機能を読み込む」で、このフォルダーを選択します。
4. 対象の動画タブを再読み込みします。必要に応じて拡張アイコンをツールバーに固定してください。

製品の使用に npm install やビルドは不要です。組織の管理ポリシーで拡張の追加が禁止されているブラウザーでは、許可されたブラウザーを使用してください。

## 操作

- **プレーヤーの顔ボタン**：そのプレーヤーの動画を加速。もう一度クリックすると解除します。
- **Sキー**：表示中の動画を加速・解除します。キーは設定で変更できます。
- **ポップアップの Go!/Stop!**：現在のタブの動画を加速・解除します。
- **3秒経過**、動画終了、動画の差し替え、ページ内の別の場所のクリックでも解除します。

加速中はミュートし、解除時は**開始直前の再生速度・音量・ミュート状態**に戻します。1.5倍速や音量0の設定も保持します。複数の動画がある場合、顔ボタンは所属プレーヤーを、キーとポップアップは表示中・再生中の動画を優先して操作します。入力欄、IME変換中、キー長押しでは動作しません。

OSで「視差効果を減らす」等を設定している場合、顔は切り替わりますが回転を抑えます。

## 設定

拡張アイコンをクリックするか、拡張機能の詳細画面から「拡張機能のオプション」を開きます。

- **高速化キー**：空白以外の1文字。初期値は `S` です。
- **対応サイト**：1行にホスト名またはHTTP(S) URLを入力。初期値は `youtube.com` と `nicovideo.jp` です。URLは保存時にホスト名へ正規化します。
- 登録したホストとそのサブドメインが対象です。`youtube.com` の登録で `www.youtube.com` が有効になり、`notyoutube.com` は有効になりません。
- サイト一覧を空にして保存すると、すべてのサイトで無効になります。

保存内容は既に開いているタブにも反映されます。拡張自体のインストール・更新後は、コンテンツスクリプトを読み込むためタブの再読み込みが必要です。

## サイト対応と制約

| 対象 | 実装方式 | 確認範囲 |
| --- | --- | --- |
| YouTubeのデスクトッププレーヤー | 下部の右操作列に顔ボタンを追加。代替の操作列・ページ内遷移・コントロール再生成にも追従 | YouTube相当のDOMで検証。実サイトでの統合は未検証 |
| ニコニコ・追加登録したサイト | HTMLの `video` 要素の直下に汎用ボタンを配置 | 汎用HTML動画で検証。各サイトの現行レイアウトは未検証 |
| iframe内、閉じたShadow DOM、独自描画プレーヤー | 現状のトップ文書の探索では動画を取得できない場合あり | 対応を保証しない |
| DRM動画・ライブ配信・サイト側が速度を固定する動画 | ブラウザー／サイトが速度変更を拒否・上書きする場合あり | 拒否・上書き時は加速表示を解除 |
| Shorts固有UI・ネイティブPiP | 専用ボタン配置は未実装 | 通常プレーヤーとは別途対応が必要 |

YouTube以外の全画面表示では、サイトが動画要素だけを全画面化すると汎用ボタンが画面外になります。その場合はキー操作を使用してください。汎用ボタンの配置はサイトのレイアウトによって調整が必要な場合があります。

### 16倍速より速くできる？

この環境の Chromium 154 では `playbackRate = 16` は受け付けられ、32・64・128の指定は `NotSupportedError` になりました。ブラウザーやプレーヤーで上限は異なりますが、本拡張では動作を確認した16倍速を使います。シークを繰り返す方式、広告の強制終了、ネットワーク応答の改変は実装していません。

### 広告ブロッカーとして検出される？

本拡張はユーザー操作でHTML動画の再生速度とミュートを変更します。広告リクエストの遮断、広告DOMの削除、フィルターリスト、検出を隠す処理はありません。ただし、サイト側は再生速度や追加UI等を観測できるため、**広告ブロッカー判定を受けないことは保証できません**。広告が表示された状態・ログイン状態・サービスの更新によって結果は変わります。実サイトでの判定は未検証です。

権限は `activeTab` と `storage` のみです。ユーザーが任意のサイトを登録できるよう、コンテンツスクリプト自体はHTTP(S)ページに読み込まれます。動画探索・DOM監視・ボタン設置は登録サイトだけで行い、外部API・アクセス解析・AIサービスへの通信は行いません。

## 開発とテスト

Node.js 24以上とChromiumを使用します。依存はテスト専用です。

```bash
npm ci
npm test
npm run check
```

別のChromium実行ファイルを使う場合：

```bash
CHROMIUM_EXECUTABLE_PATH=/path/to/chromium npm test
```

Chromiumは別途必要です。`playwright-core` はブラウザーを自動ダウンロードしません。書き込み可能なnpmキャッシュが必要な環境では、`npm ci --cache /tmp/geno-npm-cache` を使えます。

テストは実ブラウザーのDOM・動画要素・ローカルメディアを使い、Chromeのstorage/messaging APIだけを代替します。状態復元、3秒タイマー、顔と回転、複数動画、SPA遷移、設定反映、無効入力、別タブ通知、Chrome APIのエラーを確認します。拡張としての読み込み、画像リソース公開、実サイトのDOM・広告判定までを保証するテストではありません。

今回のクラウド環境では、Chromiumの管理ポリシーで拡張追加が禁止され、YouTube・ニコニコへの接続もプロキシから403で拒否されました。実機確認は次の項目を許可されたブラウザーで行ってください。

- YouTubeの通常・シアター・全画面で顔ボタンが1つ表示されること。
- 動画切替・広告切替後のボタン表示、クリック／キー／Go!/Stop! と3秒復帰。
- ニコニコや追加サイトでの配置、キー変更・サイト追加の即時反映。
- 元の速度・音量・ミュートの復元と、別タブの動画を変更しないこと。
- 実際に広告が出る状況で、サイト側の警告や操作制限が発生しないか。
