# Geno Skip 実装・レビュー記録

ユーザーの実装・commit・push指示を受け、元の `master` の `f49dba8` から `feat/player-geno-button` で実装した。既存の隔離されたクラウドチェックアウトを使用した。

## 実装

- YouTube操作列とHTML動画用の汎用顔ボタン。加速中は怒り顔＋回転、16×表示。解除すると穏やかな顔に戻る。
- キー・ポップアップ・顔ボタンを同一の加速状態へ統合し、3秒後に元の速度・音量・ミュートを復元する。
- 設定画面でキーとサイトを変更可能。ドメイン検証、開いているタブへの即時反映、保存失敗・操作不可の表示。
- 動画に関係するDOM・サイズ・祖先の表示変更を監視。固定間隔のポーリングや外部通信を追加しない。

## 自己レビューと独立レビュー

自己レビューでは、画面外の動画へのボタン未設置、同一プレーヤーの複数動画による重複、サイト側の速度変更で加速表示が残る問題を修正した。

`superpowers:executing-plans` / `superpowers:requesting-code-review` に従い、実装を担当していないレビューエージェントが `f49dba8..a6941c0` を確認した。Criticalは0件。次の3件をImportantとして再現し、すべて修正した。

| 指摘 | 原因と修正 | 検証 |
| --- | --- | --- |
| 操作列の内部だけ作り直すとボタン消失 | 自分のボタン削除を除外していた。削除されたボタンも再設置の契機にする | ナビゲーションイベントなしの操作列交換でRED→GREEN |
| 絶対配置の動画でボタンが裏に隠れる | 通常の動画直後へ挿入していた。配置コンテナとクリッピングを考慮し、外側へボタン行を置く | 実座標とelementFromPointによるクリック可能性でRED→GREEN |
| 非表示プレーヤーを表示してもボタンなし | 初回に隠れた動画を除外し、サイズ・表示変更を監視していなかった。動画ResizeObserverと祖先の属性監視を追加 | 祖先display:none→blockでRED→GREEN |

記号キーのShift問題はMinorとして報告されたが、設定できても操作できない利用者影響からImportantへ引き上げた。Shiftが必要な記号は使用可能にし、Shift英字・Ctrl/Alt/Meta・入力中は従来どおり除外する。記号キーの再現テストでRED→GREENを確認した。保留したMinor指摘はない。

最終修正は実装担当が1回の修正工程で行い、回帰テストで検証した。修正後の再レビューは実施していない。

## 検証結果

- `npm ci --cache /tmp/geno-npm-cache --ignore-scripts --no-audit --no-fund`：成功。
- `npm test`：29件、全件成功、スキップ0件。
- `npm run check` と `git diff --check`：成功。
- 実ブラウザーのDOM・動画要素・ローカルWAV再生で加速と復帰を確認。Chrome storage/messaging APIは代替している。
- ローカルのFullscreen APIを使い、プレーヤー内ボタンの操作とreduced-motion設定を確認。設定画面のスクリーンショットを目視確認した。
- Chromium 154で16倍速は受理、32・64・128倍速はNotSupportedError。より大きい倍率やシークによる代替は追加していない。

## 実装時の判断

- 既存のクラウドチェックアウトを継続使用：不要なworktreeを作らない。作業は専用ブランチに保持する。
- 「クリック中」は加速状態として扱い、押し続け操作へは変更しない：既存の3秒トグルを維持する。押し続け操作が必要なら別途仕様変更が必要。
- 顔画像は添付を参照して画像生成ツールで整えた透過素材：インライン添付はローカルファイルとして提供されておらず、元写真と同一ピクセルではない。
- 設定検証は新しい共有 `settings.js` に集約：ポップアップとページで解釈を一致させる。manifestとpopupの読み込み順に依存するためテストで固定した。
- 通常・怒り顔を1枚のスプライトにまとめた：画像取得を1回にする。左右半分の配置に依存するためCSS状態テストを置いた。
- ポップアップの顔から宣伝動画を開く旧動作は削除：顔は加速状態の表示に統一する。以前の宣伝動画へのショートカットはなくなる。
- 記号キー問題をImportantへ引き上げ修正：設定したキーが動かない状態を残さない。Shift英字を無視する仕様は維持する。

## 未検証・制約

- 管理ポリシーが拡張追加を禁止しており、実拡張の読み込みと画像の公開設定を含む最終確認はできていない。
- YouTube・ニコニコへの接続はプロキシの403で拒否され、実サイトの広告・ログイン・現在のDOMとの統合は未検証。
- 広告遮断・広告DOM削除・検出回避は実装していない。サイトは速度変更や追加UIを観測できるため、広告ブロッカー判定を受けないことは保証しない。
- iframe、閉じたShadow DOM、独自描画、DRM・ライブ、動画要素単体の全画面などの制約はREADMEに記載した。
